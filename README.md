Bites & Clicks Website
A modern, interactive landing page for an Instagram-based food and photography passion project exploring the authentic flavors and scenic beauty of Kerala.

Features
Cinematic Scroll Animation: A high-performance, scroll-bound hero section utilizing an HTML5 <canvas> to smoothly scrub through a 300-frame image sequence (split/ezgif-frame-1.png to ezgif-frame-300.png).

Dynamic Text Overlays: Scroll-triggered features that fade in and out, highlighting local cuisine, stunning landscapes, and a clear call-to-action.

Instagram Integration: Dedicated sections embedding Reels and a responsive gallery directly from the @bites.clicks feed.

Responsive Design: A mobile-first layout ensuring perfect aspect ratios and seamless viewing across all devices.

Feedback Form: A clean contact section for user suggestions and direct email routing.

Technologies Used
Frontend: Semantic HTML5, Modern CSS

Design System: Earthy, minimalist Kerala backwaters theme (Primary colors: #F5F1E7 and #3B2C24)

Animation: JavaScript (GSAP / ScrollTrigger / native requestAnimationFrame for canvas rendering)
